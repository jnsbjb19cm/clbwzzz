# 无尽试炼与秘境远征：单人首版（2026-10-20）

## 本版范围

入口：野外冒险的目的地列表 → 无尽试炼 / 秘境远征。

“无尽冒险”在界面中暂命名为“秘境远征”，避免与“野外冒险”混淆。两者都是单人玩法；玉米炮手视频提取、高清修复继续暂停。

这是本机存档的单人首版，不是联机权威模式。卡牌、远征币、道具均属于本局，不扣永久背包，不发永久金币/DNA，不计入正式主线、排行或服务器奖励。自带卡组只复制有效实例，保留品质、强化与洗练信息；标准卡组和自带卡组分开记本机最高成绩。退出或刷新不会重抽已揭晓事件，未结算战斗可以从本层重进。

## 已实现规则

### 无尽试炼

- 可选均衡小队、植物守卫、怪物突击三套借用卡组，也可复制当前选中的战团。
- 每层的敌军由植物和怪物混编；开战前展示阵容与数量。每五层切换一组敌军主题，每十层为精英战。
- 第 F 层总敌军数为 min(100, 4 + 2F)。同时在场敌军上限 24，后续单位排队入场；敌方召唤也受此上限约束。
- 基础生命倍率为 1 + 6.5% × (F−1)，基础攻击倍率为 1 + 3.5% × (F−1)。精英层分别额外乘 1.2 / 1.1。精英后的普通层会回落一小段，属于阶段难度峰值。
- 为避免无穷数值，生命倍率封顶 1000，攻击倍率封顶 600，敌方基地生命封顶 100000。这不是保证无限可通关的平衡方案。
- 通关第 5、10、15…层后获得一次换卡机会，从局内储备替换一张上阵卡；可跳过，不累积。
- 每胜一层基地恢复 80 生命，并获得 25 + min(75, 已胜场数 × 2) 远征币。每个五层营地可花 40 远征币修复 200 生命一次。
- 清除该层全部敌军或击破敌方基地获胜；己方基地归零或超过七分钟失败。战斗途中返回不算已胜，不发补给。
- 本版不带英雄主动技能或局外天赋加成，减少标准卡组挑战受账号养成的影响。

### 秘境远征

每次选择当前节点：一条战斗路线，加两条不同的非战斗路线。最多连续走两个非战斗节点；每第五节点保证战斗。难度按照已经完成的战斗数增长，而不是靠逛商店累加。

| 事件 | 当前内容 |
| --- | --- |
| 战斗 | 展示敌军后开战，沿用试炼的混编和成长规则 |
| 奖励 | 三选一：60 远征币、未知药瓶、一张本局援军卡 |
| 随机 | 45% 奖励、35% 中性、20% 负面，进入即揭晓并保存 |
| 中性 | 花 25 远征币恢复基地 20% 生命，或不花费离开 |
| 负面 | 支付 20 币；或损失 10% 基地最大生命（不直接致死）；或接受基础生命 −10% 的荆棘诅咒 |
| 换卡 | 使用储备替换一张上阵卡，或跳过 |
| 商店 | 购买援军卡、猎手獠牙、余烬契约、破损补给包；每件每店限购一次 |

战斗奖励只入局内账本。基地损伤带入下一场；远征不会像试炼那样每胜一场免费恢复 80 生命。新卡先进入储备，需要换卡节点才能上场。每局卡牌总数上限 60，道具上限 12；达到上限后相应领取或购买选项禁用。

道具效果：
- 猎手獠牙：上阵卡牌基础攻击 +10%。
- 古树护符：上阵卡牌基础生命 +15%。
- 余烬契约：基础攻击 +18%，基础生命 −8%。
- 破损补给包：每场初始阳光、食物各 +6，基础攻击 −5%。
- 荆棘诅咒：基础生命 −10%。
- 疲惫印记：基础攻击 −8%。
- 未知药瓶：获得时等概率转为猎手獠牙、古树护符或疲惫印记；结果立即可见，不在每次开战时重抽。

同维度道具加算，不连乘；基础攻击/生命倍率限定在 0.5–2.5，初始资源增量最多 30。这里的“基础”指卡牌原始攻击/生命，经品质、强化计算后用于部署；并不修改永久卡牌，也不自动强化其额外召唤物。

## 2026-10-21 第二批（已实装）

### 十层契约

每通过 10 场战斗（试炼按已通过层数，远征按已完成战斗数）强制签一项契约，三项三选一，签约立刻发放远征币：

| 契约 | 效果 | 立刻获得 |
| --- | --- | --- |
| 迅捷之约 | 敌方移动单位移速 +20% | 60 远征币 |
| 齐射之约 | 敌方远程单位攻击 +18% | 70 远征币 |
| 复苏之约 | 敌方每 2 秒回复 1.5% 最大生命 | 80 远征币 |

契约可叠加，加成封顶：移速 +60%、远程攻击 +54%、回血 4.5%/2 秒。只改机制，不改敌方基础攻击/生命成长，避免继续堆数值。试炼第 10 层签完契约后仍进入五层营地（换卡/修复机会保留）。

### 五层侦察

营地（试炼）和路线页（远征）会预告当前五层区间：主力敌军卡种与前 4 名数量、敌军主题、精英层位置（精英：生命 ×1.2 / 攻击 ×1.1）。只给区间级情报，不泄露完整阵容。

### 可选赏金

每场开战前（`ready`）可从三项里选一项，再点一次取消；失败没有任何惩罚，只影响本场额外远征币：

| 赏金 | 条件 | 额外奖励 |
| --- | --- | --- |
| 无瑕防线 | 本场基地不损失生命（按真实受击统计，治疗不能抵消） | +80 远征币 |
| 三路并进 | 本场至少在 3 条不同路部署卡牌 | +60 远征币 |
| 精兵简政 | 本场最多使用 4 种不同卡牌 | +70 远征币 |

赏金统计直接取自真实战斗引擎：部署时记录路数与卡种，`damageBase('player')` 记录基地受击。

### 战场地图

试炼与远征统一使用 **PVE 的草地战场**（`resources/background/grassbg.png` + 蘑菇柱），不再走新手教程/训练营的旧黄沙兜底；新手教程本身也固定使用草地地图。

### 界面适配与性能（2026-10-21 修复）

- **页面滚动**：`#view-root` 是 `position:absolute; overflow:hidden` 的固定容器，无尽页面原来只有 `min-height:100%`，内容一高就被父级裁掉且 `overflow:auto` 永远不生效（1920×1080 下都会裁掉底部卡组/旅程记录）。现在页面 `height:100%` 自己当滚动容器（`overflow-y:auto`），1024×768、1366×768、800×600、640×480、480×800、390×844 等尺寸都能正常滚到底。
- **矮屏/窄屏**：新增 `@media (max-height:760px)` 压缩页头与统计条；`@media (max-width:560px)` 下页头按钮不换行、标签页二等分、卡牌尺寸缩小，避免标题/返回按钮/底部按钮互相挤压。
- **战斗内「返回挑战」**：窄屏（≤760px）把它抬到底部按钮组上方，不再和「技能/放置/设置/退出」重叠；各分辨率下都完整在视口内。
- **新手教程聚光灯**：原来用 `box-shadow: 0 0 0 9999px` 做全屏遮罩，元素绘制边界被撑到视口外上万像素，低配设备上每帧重绘代价很高。现在改成四块纯色遮罩矩形围出高亮框、focus 只画边框和小光晕；`tutorial-direct-highlight` 的呼吸动画也从 `filter: brightness` 改为纯 `transform`；教程 monitor 的倒计时/聚光灯只在值真正变化时写 DOM。CPU 6 倍节流模拟下教程平均帧率约为旧实现的 2.1 倍（19.4 → 41.7 FPS），p95 帧时间减半。
- 回归脚本：`scripts/verify-endless-ui-responsive-20261021.mjs`（66 个分辨率×页面/战斗断言）、`scripts/verify-tutorial-map-animation-20261021.mjs`（草地地图 + 动画流畅度 + 聚光灯多分辨率）。

### 战斗运动平滑（2026-10-21）

用户反馈：「只有可移动卡牌本体和子弹的帧率异常」。原因是 2026-10-13 起引擎改为固定步长 TICK_INTERVAL=0.155s 推进，渲染仍按 requestAnimationFrame 跑；姿态动画时钟已经用 `engine.animationTime` 平滑，但**位置**（`unit.col` / `projectile.x/y`）只在 tick 时更新 → 移动单位和子弹实际只有约 6.45 次/秒的位置更新。

修复方式（`src/battle/BattlePresentationInterpolation20261021.js`，纯渲染层、不改战斗判定）：
- 每次 `engine.tick` 前记录单位上一次 `col`；渲染前用 `alpha = 本帧模拟余量 / TICK_INTERVAL` 把 `unit.col` 临时外推 `current + (current-prev)*alpha`，画完立即还原；
- 子弹轨迹在发射时已解出解析解（`flightStartCol/Vx/Vy/抛物线参数`），渲染时用 `t = flightElapsed + alpha*step` 直接算位置、弧高和贴图帧时钟；
- PVP/联机权威战斗有自己的快照插值，跳过；战斗结束/暂停时不插值；
- 回归脚本 `scripts/verify-battle-motion-smoothness-20261021.mjs`：移动单位 1 秒内不同渲染位置 8 → 80，子弹 8 → 200。

无尽试炼/秘境远征的战斗房间与冒险大陆 PVE 战斗完全一致（草地 + 蘑菇柱 + 同一套 BattleView/全屏布局），不使用新手教程的训练场房间。

## 推荐下一批玩法（尚未实装）

1. **阶段撤退**：十层节点可带走部分正式奖励，继续挑战则提高收益和风险。须先接服务端权威结算、幂等领取和奖励上限，不能从本机存档直接发正式资源。
2. **周赛同种子**：全体玩家挑战相同敌军、相同事件；借用卡组和自带卡组分榜。正式榜单必须使用服务端战斗验证。
3. **远征道具组合**：例如三件补给类道具触发一次免费换卡；可购买移除诅咒服务。先控制叠加上限，再加套装。
4. **地图变化**：五层一组天气或地形机制，限制同屏复杂特效。暂不加入永久禁止某类卡牌的硬克制，以免随机路线直接判负。

优先建议做 1、2：能明显改变长期目标，且不用立刻扩大永久经济或联机范围。

## 后续联机落点

当前规则计算、存档、战斗接入和界面分开。联机版可以复用事件与生成规则，但不能信任客户端提交的层数、金币或胜负：
- 服务端持有 runId、随机种子、状态版本、队员名单和当前事件。
- 开战锁定卡组快照；战斗使用现有服务端权威引擎。
- 队伍路线/换卡选择使用投票或队长确认，必须有超时、掉线重连规则。
- 领取使用幂等键；跨设备继续、正式排行、永久奖励均以服务端记录为准。
- 单人本机成绩不迁入正式排行榜，防止客户端可编辑存档污染排行。
