## 6. 结论与建议

### 6.1 机制加权后谁超标 / 谁偏弱

机制加权**最强 5 张**：#61黑铁土豆雷(z4.00)、#68树精守卫(z3.29)、#52强化地刺(z2.67)、#2核桃卫兵(z2.65)、#109重生史莱姆(z2.04)

### 6.2 强化系统

- **不要改成"加 1/加 2"这种固定加值**：高攻卡（如 750 攻）几乎无感，低攻卡（4 攻）却会翻几倍，**会直接把平衡打散**。
- 推荐 **D 封顶**（保留 8%/星的手感，但总计封顶 +60%）或 **C 递减**（前 5 星提升明显，后 10 星放缓），两者都能"削弱上限而不砍手感"。
- 若必须简单：**B 减半（4%/星）** 是最小改动，满级攻击从 +120% 降到 +60%。
### 6.3 冷却

- 现行表最大问题是 **3.0 → 2.0 的断崖（−33%）**，以及 **8.6 与 5.0 之间差 42%**；
- 建议改用**平滑表**（7.2 / 5.4 / 4.5 / 3.9 / 3.4 / 2.9 / 特殊 2.5），相邻档差控制在 15%~25%，
- 同时把 `Math.max(6, ...)` 的**冷却下限**与新表一起检查（避免高星缩减后所有卡都压到同一档）。
