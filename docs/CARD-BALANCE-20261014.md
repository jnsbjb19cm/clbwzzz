## 1. 口径与盲区

- 秒伤 DPS = 攻击 ÷ 冷却（冷却取 `getAttackCooldown(攻速档)`；攻速档 0 = 不攻击 → DPS 记 0）
- 每费血 = 血量 ÷ 费用；每费秒伤 = DPS ÷ 费用
- 综合值 = 每费血 × 1 + 每费秒伤 × 3；再**按品质档位**标准化（z-score），综合分 = 50 + 15z（0~100）
- **盲区（务必结合看）**：① 坦克/辅助攻=0 → 只看血量；② 召唤/技能卡价值在产出，数值必然低；③ 范围/爆发卡单发高攻 ≠ 每秒高；④ 控制/持续伤害等机制无法用单一数字表达。

## 6. 结论与建议

1. **黑铁土豆雷（#61）**：数值上攻击 750 显著异常，但**实测可控**（可用任意诱饵单位骗走即失效），因此**不建议按数值削弱**。

2. **坦克类**（核桃卫兵 #2、树精守卫 #68、史莱姆 #107/#109）在"每费血"维度偏高：若同费用产出明显超出，可优先微调**费用 +1** 或 **血量 −8%~12%**，不要动冷却。

3. **薄血射手类**（冰霜射手 #84、三头仙人掌 #25）血效明显偏低：它们靠射程/机制换血，若要增强建议**加血**（+15%~25%）而不是加攻，避免 DPS 通胀。

4. **召唤/控制类**（怪物工厂 #66、魅惑妖灵 #53）数值必然低，请以**机制强度**单独评估，勿按本表直接加强。

5. 建议每档先定一条**基准线**（本表第 2 节的均值/中位），新卡一律对齐基准，再谈机制加成。
